Teller Status & Cost

Live view of the Teller bank-sync integration. Active enrollments are tracked via the Worker's /teller/exchange and /teller/disconnect routes (running counter in KV). Webhook health uses the timestamp of the most recent /teller/webhook POST — green if within 24h, yellow 24-72h, red older or never received with active enrollments.

Estimated monthly cost = active enrollments × TELLER_COST_PER_CONNECTION_USD from wrangler.toml. Sandbox and development environments always show $0 because Teller does not bill for them. The cost becomes real only when TELLER_ENV is flipped to production in wrangler.toml.

OpenCellID Quota

Cell-tower geolocation usage for the day. The Worker proxies all OpenCellID lookups through /cell/lookup (key lives as a Worker secret, not in the APK) and caches each tower for 7 days, so this counter only grows when a previously-unseen tower is looked up.

Watch levels (free tier cap = 1,000 / day):
< 50% — green, plenty of headroom.
50–79% — yellow, monitor; usually still fine but worth a glance.
≥ 80% — red alert. The Worker will start refusing lookups at 100% and resolveCell falls back silently to GPS / IP. Either raise OPENCELLID_DAILY_CAP in wrangler.toml and redeploy, or upgrade the OpenCellID plan.

The OpenCellID dashboard shows lifetime totals and per-token analytics not captured here — bookmark it for trend visibility: https://my.opencellid.org/dashboard → Access Tokens / Analytics.
