Free SaaS enhancers (optional)

These add nicer dashboards (referrers, countries, devices) on top of PocketBase. Privacy-friendly / cookieless — usually no GDPR banner. Defaults live in /scripts/site-analytics-saas.js; optional override via window.JOSSPATECH_ANALYTICS before that script.

1. Cloudflare Web Analytics — free forever

Best if you already have a Cloudflare account. Standalone beacon works on GitHub Pages (no DNS proxy required).

  1. Open Cloudflare dashboard → Analytics & logs → Web Analytics → Add a site (manual).
  2. Hostname: josspatech.com
  3. Copy the token → set cloudflareToken in JOSSPATECH_ANALYTICS on the site.
  4. View stats in the Cloudflare Web Analytics UI (not pulled into this admin yet).

2. GoatCounter — free hosted (great for GH Pages)

Tiny script (~1KB), UTM/campaign friendly, open source. Free for normal public sites.

  1. Sign up at goatcounter.com.
  2. Create site → copy count endpoint like https://YOURCODE.goatcounter.com/count.
  3. Set goatcounter in JOSSPATECH_ANALYTICS on the site → push Pages.
  4. Dashboard lives on GoatCounter; good cross-check against PocketBase.
